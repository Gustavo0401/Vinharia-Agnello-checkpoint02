# vinharia-agnello-checkpoint02

Sistema básico para cadastro e análise de vinhos artesanais da Vinheira Agnello

Adicionado a validação dos dados de entrada, a contagem de cadastros, a verificação de estoque baixo e a classificação dos vinhos por idade (jovem, amadurecido ou antigo), ao final o sistema resume com estatísticas gerais e qual é o vinho mais antigo do catálogo.
